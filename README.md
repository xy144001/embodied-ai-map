# 具身机器人技术地图

一个由三位维护者共同建设的静态知识网站，分为灵巧手、双臂和全身机器人三个并列分区。项目使用 Astro 生成纯静态页面，并通过 GitHub Actions 自动校验和部署到 GitHub Pages。

## 分工

- 灵巧手：`@starrysky77`
- 双臂：`@xy144001`
- 全身：`@SyouSanGin`

## 本地运行

```bash
npm install
npm run dev
```

提交前运行：

```bash
npm run validate-content
npm run build
```

详细协作方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。
